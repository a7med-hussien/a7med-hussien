# 💫 About Me:
I build full-stack web applications with Laravel on the back end and Vue.js or React on the front end — from CRM and admin dashboards to customer-facing SaaS products. Over 8 years I've worked as a full-stack developer, most recently building a suite of B2B platforms from the ground up for a NYC-based company.<br><br>Recent work includes CRMzz, a CRM and sales outreach platform with Stripe/Braintree billing, Algolia search, real-time chat, and AI voice-calling integration for automated outreach; AgingCareNet, a client management platform for the aging-care industry with automated SMS/email communications (Twilio, SendGrid) and PDF document generation; and VnuMngr, an event and venue management dashboard with drag-and-drop scheduling, calendar booking, and Gantt-based timelines.<br><br>I care about clean, maintainable code and clear communication — you'll get status updates without having to chase me
